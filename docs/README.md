# 食间校园食堂共建网站：项目文档

版本：v0.3｜更新日期：2026-10-13｜当前工作区实现基线

## 使用说明

- 以本地源码为基准，包括尚未提交 / 上传的最近改动；不保证 GitHub 远端已经同步本版文档。
- 已实现、演示限制、后续需求分开描述。代码具备流程不代表已取得学校授权或完成公开部署验收。
- 推荐票、互动、MySQL、审核员和图片描述已经实现；真实登录、收藏、举报申诉、完整审计和积分兑换尚未实现。
- 规格说明书采用 Mermaid 绘图。GitHub 或支持 Mermaid 的 Markdown 阅读器可直接显示；不支持时看到代码块，图源码仍可编辑。
- DFD 的 D1–D5 是 app_state.payload 内的逻辑分区，D6 是 app_media；不要把它们误读成已存在的六张业务表。
- 早期调研的开源项目和法规链接保留原调研性质，不表示本次更新重新验证了许可证或上线法律要求。

## 当前运行基线

普通启动可连接本机 MySQL，也可在未启用数据库时使用浏览器 localStorage；远端脚本连接腾讯云 MySQL。四个演示身份可切换，管理员和审核员权限有操作校验，但没有可信认证。

MySQL 数据库默认为 canteen_guide_mvp：业务文字集中在 app_state，一行 JSON；图片二进制在 app_media。备份表用于特定迁移。不同服务器的同名数据库是独立数据，不自动同步。

教师或项目评审可先阅读规格说明书中的功能分解、权限矩阵和 DFD，再结合技术方案判断当前实现与正式多用户版本的距离。
