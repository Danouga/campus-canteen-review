## 阅读说明

- 这是供讨论、估算和后续开发使用的草案，不代表学校已经授权，也不表示已完成合规审核。
- 文中 **确定需求** 来自提出的功能；**建议规则** 是为了让系统可实现、可测试而拟定的默认值，正式开发前可调整。
- `MVP` 指首个可在小范围真实使用的版本；`V1` 指在试运行后补齐社区与共建能力的版本。
- 时间、成本和性能数字都是规划假设，应在确认学校规模、团队与部署条件后重估。

## 当前总体范围

先建设一个适配手机浏览器的校园网站，覆盖学校两个校区。店铺资料可从空白开始，用户通过加号发起共建申请，管理员审核后暂示或固定，也可直接编辑和下架资料。MVP 暂不确定普通用户登录凭证；后续开放推荐票、评论、美食贴和基础推荐。不设置星级打分功能。三维食堂、AI 推荐、微信小程序、赞助先预留“规划中”入口。
