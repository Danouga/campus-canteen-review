# 食间 · 校园食堂共建网站 MVP

这是一个可运行的**界面与流程原型**。覆盖两个校区，食堂和店铺默认留空；用户可从加号提交共建申请，管理员预览页可审核后暂示 24 小时或直接固定，也可直接维护食堂与店铺资料。首页与食堂展示分开，食堂展示页始终保留添加食堂卡片。支持食堂照片、店铺门面与菜品照片、菜品详情与多图、店铺/菜品/美食贴评论、富文本美食贴和简单内容筛选。

## 运行

需要 Node.js 20 或更高版本，以及本机 MySQL 8.0。首次运行先安装依赖：

```powershell
npm install
npm run dev
```

当前本机配置位于被 Git 忽略的 `.env.local`，服务地址默认为 `http://127.0.0.1:4174`。`npm run check` 检查 JavaScript 语法，`node tests/contribution-smoke.mjs` 检查共建审核、消息、内容归属、删除和菜品多图的数据流程。数据库连接失败时服务不会启动，避免误写入浏览器备用数据。

如需补充可识别的演示内容，在服务启动且确认连接本机 MySQL 后运行 `node scripts/seed-demo.mjs`。脚本会在一个已有食堂下添加“【测试】清新小食”、两道测试菜品、三条演示评论和一篇测试帖子；重复运行不会添加同名内容。

## 当前数据模式

- 已接通本机 MySQL 8.0。服务端自动创建 `canteen_guide_mvp` 数据库与 `app_state` 表，以一行 JSON 保存当前 MVP 的完整预览状态。`src/api-repository.js` 通过本机 HTTP API 调用服务端；浏览器不会读取数据库密码。服务端只监听 `127.0.0.1`，且静态文件路由不会提供 `.env.local`。
- MySQL 配置只保存在被 `.gitignore` 忽略的 `.env.local`。未配置 `DB_MODE=mysql` 时自动使用浏览器 `localStorage`；两种模式的数据不会自动迁移。
- 当前单行 JSON 存储适合本机原型验证，正式多用户版本需要拆分数据表、独立图片存储、事务与审核权限。右上角“用户信息”侧栏可切换“发布人、浏览人、管理员”三种演示身份，查看审核消息和自己的发布；它们不是真实登录，浏览器或 API 可以伪造管理员身份。屏蔽词也只有少量示例词。**不可直接公开部署。**
- 为避免凭空造学校资料，两校区暂用“校区一/校区二”占位名。管理员可在管理预览页修改。食堂与店铺均从空白开始。

## 可试用的流程

1. 从首页进入“食堂展示”，切换校区；即使已有食堂，也可点击“添加食堂”卡片申请补充。
2. 从右上角“用户信息”切换为“管理员”进入管理工作台，将申请暂示 24 小时、直接固定或驳回；也可直接添加/编辑/下架与恢复食堂、店铺，管理菜品和图片。切回申请人后，在侧栏“我的消息”查看审核结果、说明和未读标记。侧栏“我的发布”展示现有帖子及内容数量，推荐票数暂为占位。
3. 进入已固定的食堂，申请添加店铺；进入店铺查看菜品、图片、营业时间和评论的空状态。
4. 点击食堂、店铺或菜品信息，可以只勾选一项资料提交修改，也可一次选多项；从详情页发起时，上级位置固定并隐藏对应选择器，避免误选。点击店铺标题中的标签可展开标签窗口，空白卡片用于申请追加标签，多个标签用逗号分隔；旧标签不会被覆盖。窗口内心形赞同/反对按钮是未启用的占位。原有“分类”资料仍会显示为标签。审核卡片展示完整位置和新增菜品价格。新增菜品可填写“名称或口味”并附照片。
5. 食堂标题旁可查看照片，图片窗口最后一张空白卡片用于申请上传。店铺标题图、菜品缩略图也打开同一类图片窗口。店铺图片可选择“菜品照片”或“店铺门面”；菜品详情可展示多张图片。食堂、店铺卡片顶部会展示已有图片。超过 900KB 的 JPG/PNG/WebP 上传会先在浏览器压缩，仍无法压到限制内时会提示失败。
6. 点击“美食贴”发帖，关联店铺，在富文本编辑器中调整加粗、斜体、标题、列表并插入图片。点击美食贴或菜品卡片的空白区域可进入详情页，卡片上的独立“详情/阅读详情”按钮已移除；菜品字段编辑按钮仍用于修改资料。店铺、菜品和美食贴共用评论组件，暂不开放回复。
7. 以“发布人”发布评论、图片和帖子后，可以删除自己的内容；切换为“浏览人”不能删除别人的内容。这里的删除是下架，记录仍留在演示数据中。管理工作台可清空本地测试数据，回到两个校区的空白状态。

## MVP 范围说明

公开用户登录、推荐票、排行榜、美食贴收藏/赞同/反对及共建态度投票仍未接入。右上角“网站评价规则”列出拟议的隐藏门槛与额外推荐票规则，均明确标记为未启用。正式开放互动前，需要学校登录接口或其他可识别用户的方案，以及服务端审核和权限控制。三维食堂、AI 推荐、微信小程序和赞助仅显示“规划中”页面。
