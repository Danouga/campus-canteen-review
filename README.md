# 食间 · 校园食堂共建网站 MVP

这是一个可运行的**界面与流程原型**。覆盖两个校区，食堂和店铺默认留空；用户可从加号提交共建申请，管理员预览页可审核后暂示 24 小时或直接固定，也可直接维护食堂与店铺资料。首页与食堂展示分开，食堂展示页始终保留添加食堂卡片。支持菜品照片、与菜品关联的图片、店铺封面、美食贴本地演示和简单内容筛选。

## 运行

需要 Node.js 20 或更高版本，无需安装 npm 依赖。

```powershell
npm run dev
```

浏览器打开 `http://127.0.0.1:4173`。用 `npm run check` 检查 JavaScript 语法。端口可用 `PORT` 环境变量调整。

## 当前数据模式

- 界面调用 [`src/repository.js`](./src/repository.js) 的异步数据访问接口，当前实现为浏览器 `localStorage`，用于界面试用和流程演示。
- [`src/api-repository.js`](./src/api-repository.js) 预留相同方法的服务端 API 适配层；**没有连接数据库，也没有写入数据库凭证**。未来需先明确数据库类型、表结构、后端部署方式和学校登录接口，再实现服务器 API 与真实鉴权。
- 本地管理员入口没有权限保护，本地评论使用演示昵称，屏蔽词只含少量示例词。**当前版本仅用于本机预览，不可直接公开部署。**
- 为避免凭空造学校资料，两校区暂用“校区一/校区二”占位名。管理员可在管理预览页修改。食堂与店铺均从空白开始。

## 可试用的流程

1. 从首页进入“食堂展示”，切换校区；即使已有食堂，也可点击“添加食堂”卡片申请补充。
2. 进入“管理预览”，将申请暂示 24 小时、直接固定或驳回；也可直接添加/编辑/下架与恢复食堂、店铺，管理菜品和图片。
3. 进入已固定的食堂，申请添加店铺；进入店铺查看菜品、图片、营业时间和评论的空状态。
4. 在店铺页提交菜品、图片、店铺信息申请。菜品可附照片；额外图片须选择对应菜品，展示说明自动取菜品名。图片只保存到此浏览器的演示数据中，单张限制 900KB。
5. 点击“发美食贴”，关联已收录店铺并发布文字或照片，帖子在“美食贴”页与店铺详情页展示。当前发帖仅用演示昵称和屏蔽词筛选。
6. 管理预览页可清空本地测试数据，回到两个校区的空白状态。

## MVP 范围说明

公开用户登录、真实数据库、推荐票、排行榜、美食贴互动（评论、收藏、赞同、反对）及共建态度投票仍未接入。美食贴目前只有本地发布与展示。正式开放互动前，需要学校登录接口或其他可识别用户的方案，以及服务端审核和权限控制。三维食堂、AI 推荐、微信小程序和赞助仅显示“规划中”页面。
